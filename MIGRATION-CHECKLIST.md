# Launch and Squarespace cancellation checklist

## Publish first

- [ ] Sign in to GitHub as `roryhartdesign`
- [ ] Create the public repository `roryhartdesign.github.io`
- [ ] Push this standalone portfolio to the repository's `main` branch
- [ ] Enable GitHub Pages with GitHub Actions
- [ ] Verify `https://roryhartdesign.github.io`
- [ ] Check the homepage, About page, all project/story routes, carousels and resume

## Cancel the Squarespace website

- [ ] Open the Squarespace Billing panel for the portfolio site
- [ ] Select the Website subscription
- [ ] Choose Cancel subscription
- [ ] Review whether service ends immediately or at the end of the billing cycle
- [ ] Review any separately billed subscriptions before confirming
- [ ] Confirm the website cancellation

## Decide what to do with `thisisrory.com`

The domain is billed separately and is not canceled automatically with the
website subscription.

- Keep it: leave domain auto-renew on and point it to GitHub Pages later
- Let it go: turn domain auto-renew off separately; it remains registered until
  its expiration date
- Before letting it expire, confirm that no custom email or other service relies
  on the domain
